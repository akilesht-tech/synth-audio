SYNTH AUDIO v19 — Mobile Fix

Built directly from v18. Existing music, server, admin, playlists, downloads, offline playback, artwork, desktop/mobile and background-player features are preserved.

Fixes:
- Restored normal vertical phone scrolling/swipe down and up.
- Removed mobile scroll containment that could interfere with Android WebView touch scrolling.
- Kept horizontal overflow disabled so the app does not drift sideways.
- Smart Playlists now use a clean two-column mobile grid instead of a horizontal strip.
- Improved smart playlist card sizing for small phones.
- Live library refresh polling reduced from 15 seconds to 5 seconds, while focus/online/visibility refresh remains enabled.
